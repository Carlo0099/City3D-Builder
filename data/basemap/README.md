# 底图服务 (Basemap Slot)

本目录用于存放用户的**离线底图切片包**（XYZ 瓦片或私有数据）。

## 目录结构推荐
```text
data/basemap/
└── {z}/{x}/{y}.png   (例如: 18/214132/112048.png)
```

## 使用说明
1. **公网免鉴权模式（默认推荐）**：系统已内置 **ESRI World Imagery（全球高清遥感卫星图）**，开箱即用，无需在此目录放置任何文件。
2. **天地图模式**：如需使用国家测绘天地图，无需下载切片，只需在 `.env` 或前端设置界面填入您在 [天地图官网](https://www.tianditu.gov.cn/) 申请的个人 Token (`tk`) 即可。
3. **完全内网/离线部署**：将通过 Python 切片工具或 GIS 平台导出的 XYZ 切片复制到此目录，并在配置中启用 `offline_xyz` 模式。
