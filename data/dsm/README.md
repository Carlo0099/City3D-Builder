# 数字表面模型 (DSM Slot)

本目录用于插槽式挂载**包含建筑物与植被的地表全标高模型**（Digital Surface Model）。

## 作用与数学原理
- DSM 记录了“地表 + 建筑物表面”的综合海拔高度；
- 核心公式：$$\text{nDSM (建筑真实净高)} = \text{DSM (表面标高)} - \text{DEM (裸地标高)}$$；
- 经由 nDSM，程序化建模引擎可直接反演得出每栋建筑物的真实物理高度与屋顶倾角。

## 推荐数据格式
- **单波段 32 位浮点 GeoTIFF (`.tif`)**；
- 投影坐标系：**WGS84 (EPSG:4326)**；
- 命名建议：`dsm.tif`。

## 4 级自适应降级链（四级决策链）
本开源管线具备高度智能容错能力，会根据用户投入的数据自动选择最佳重建路线：

1. **【最高精度】双高程融合模式 (`dem_dsm`)**：
   - 用户同时在 `data/dem/` 和 `data/dsm/` 提供栅格。
   - 系统执行数学差分：`nDSM = DSM - DEM`，真实还原每栋建筑物的厘米/分米级高度。
2. **【单栅格模式】形态学开运算滤波模式 (`dsm_only`)**：
   - 用户仅提供了 `dsm.tif`，没有独立 DEM。
   - 系统自动激活基于数学形态学的 White Top-Hat 开运算滤波器，从 DSM 中自动剥离裸地基底，自动计算出 nDSM。
3. **【二维 GIS 属性驱动模式 (`vector_only`)】**：
   - 用户没有任何 DSM/DEM 栅格。
   - 系统自动读取建筑矢量的 `height` 属性或 `floor`/`levels` 属性（按 3.3 米/层折算）。
4. **【轮廓面积启发式推定模式 (`heuristic`)】**：
   - 用户仅有建筑物二维多边形，无任何高度字段。
   - 系统基于建筑底面轮廓的周长与面积，结合城市规划经验法则自动推定合理天际线高度。

> **结论**：若您拥有无人机航测生成的 DSM，丢入本目录即可体验最高精度；若没有，留空即可，管线将平滑降级执行！
