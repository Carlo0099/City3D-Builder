# 数据插槽目录说明 (Data Slots)

为了保持代码仓库的纯净轻量，真实 GIS 大数据文件（如遥感影像、数字高程、矢量等）已被 Git 全局忽略（不会被上传至 GitHub/Gitee）。

您可以将本地的数据直接放入以下对应的子插槽中，系统启动或执行管线时会自动扫描探测：

---

### 1. `data/vector/` (建筑物二维矢量轮廓)
* **支持格式**：
  * Shapefile 套件：`*.shp`、`*.dbf`、`*.shx`、`*.prj`（同名前缀）；
  * GeoJSON 文件：`*.geojson`；
* **说明**：
  * 系统在解译时会自动读取其中的多边形几何；
  * 如果属性表中包含建筑高度（如 `height`）或层数（如 `Floor`），系统会自动解析真实高度；缺失时将采用配置的默认基线高度。

---

### 2. `data/dem/` (数字高程模型 · 裸地地形)
* **支持格式**：`*.tif` / `*.tiff` (GeoTIFF)
* **说明**：
  * 存放带有地理坐标的裸地 DEM 栅格；
  * 管线会自动执行局部双线性插值，将三维建筑基底与真实地形起伏无缝吸附贴合，并自动生成防悬空裙边（Terrain Skirting）。
  * 若目录为空，系统将自动降级为 WGS84 椭球面平地基线。

---

### 3. `data/dsm/` (数字表面模型 · 地表全貌)
* **支持格式**：`*.tif` / `*.tiff` (GeoTIFF，可选)
* **说明**：
  * 若同时具备 DSM 与 DEM，系统会自动计算差分高差 $nDSM = DSM - DEM$ 反演树木与建筑物的真实物理净高。

---

### 4. `data/basemap/` (离线底图切片)
* **支持格式**：标准 XYZ 瓦片切片目录结构 `{z}/{x}/{y}.png`（可选）
* **说明**：
  * 用于纯内网、完全断网离线环境；
  * 正常联网情况下推荐使用系统默认的免费免鉴权高分辨率卫星影像（ESRI），无需在此放置任何文件。
